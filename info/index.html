The genes for some traits only have two forms, or alleles, one of which can be dominant and the other recessive. To determine the possible outcomes when parents with these two different alleles mate we use a Monohybrid Cross Punnett square.

Punnett Squares

The Punnett square is a mathematical tool used by geneticists studying heredity to systematically show all the allelic combinations of parental gametes and to predict the offspring ratios. Heredity is the passing of traits from parent to offspring. Traits are controlled by genes, which can have different forms called alleles. There are two alleles for every trait.

For example, Gregor Mendel worked with pea plants that had a gene for pea seed color with two different alleles for pea seed color—an allele for yellow and an allele for green. When Mendel crossed a yellow-seeded pea plant with a green-seeded pea plant all the offspring of this cross had yellow seeds. Mendel determined that the yellow seed allele was dominant and the green recessive because even when the alleles for both colors were present, the yellow allele hid the green allele.

English biologist Dr. Reginald Punnett developed a simple system for predicting the ways in which alleles can combine, called a Punnett square. In a Punnett square, letters represents dominant and recessive alleles. An uppercase letter represents a dominant allele (Y), and a lowercase letter represents a recessive allele (y). Within each organism, haploid cells contains two alleles for every trait, one inherited from the female parent and one from the male parent. An organism is described differently based on the type of allele combination it has for a particular trait: allele.

Types of Crosses
Monohybrid Cross
If only one trait is being considered in a genetic cross, the cross is called monohybrid. Because each parent has two alleles to pass on, the Punnett square for a monohybrid cross is two boxes tall to accommodate both maternal alleles, and two boxes wide to accommodate both paternal alleles.

The heterozygous parent (Yy) can pass on the dominant allele (Y) or the recessive allele (y) so the first vertical box of the Punnett square is labeled Y and the second is labeled y. The homozygous dominant parent (YY) can pass on two of the dominant allele (Y) so both horizontal boxes are labeled Y. The resulting offspring are filled in accordingly.

Ratios
Allele combinations define the genotype, or the genetic makeup, of an organism for a particular trait. The phenotype is the physical trait that shows as a result of the particular genotype, like yellow or green color for peas. Given that multiple allele combinations result in the same phenotype, organisms may look alike but have different genotypes. Possible outcomes of a genetic cross can be described using either a genotype ratio and a phenotype ratio. The genotype ratio shows the number of heterozygous dominant genotypes to homozygous genotypes to heterozygous recessive genotypes: YY:Yy:yy. A phenotype ratio shows the number of each observable version of the trait, so the first value shows the number of both the heterozygous dominant and homozygous genes while the second value shows just the number of heterozygous recessive genes: YY+Yy:yy. Determining the parents of an individual offspring can be tricky when only the phenotype of the offspring is observable. But when the phenotypes of a group of offspring from the same parents is examined as a ratio, it becomes possible to narrow down the probable genotypes of those parents.

Dihybrid Cross
If two traits are being considered in a genetic cross, the cross is called dihybrid. A Punnett square for a dihybrid cross is four boxes tall and four boxes wide because each parent can pass on four possible combinations of alleles. For example, a heterozygous parent (YyRr) can pass on the following combinations of alleles: (YR), (Yr), (yR), (yr). Each box of the Punnett square is labeled with one of these possible combinations of alleles. (Graphic of dihybrid cross: FPO below)
In this example the result is 9 Yellow Round peas, 3 Yellow wrinkled peas, 3 green Round peas, and 1 green wrinkled pea. This can be described with a phenotype ratio of 9:3:3:1.
